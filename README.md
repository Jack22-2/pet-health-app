## v1.2 修复清单（第二轮走查 + 发布检查，19 项）

- **存储**：疫苗本照片入库前压缩（长边 ≤1280px、JPEG 0.7）；`save()` 捕获配额超限，避免真实照片撑爆 localStorage 后静默丢数据
- **日期引擎**：`addMonths()` 月末钳制（1/31 + 1 月 → 2/28，不再溢出成 3/3）；OCR 识别结果与示例疫苗本日期改为相对演示台「今天」动态生成，时间快进后状态自洽；改期禁止选过去日期
- **演示链路**：验证台流程⑤ 买断成功后自动进入「建立档案」表单（此前链路中断）；表单切换种类/性别不再清空已填内容
- **导航（P0，发布检查时发现）**：底部 Tab 按钮补齐 `data-act="tab"`——此前只有 `data-tab`，全局点击处理器识别不到，首页/健康/出示/我的四个 Tab 点击全部无响应（v1.1 遗留问题）
- **提醒展示**：时间线徽标改为统一走 `withStatus()` 派生，逾期/临期在首页与健康页都能正确显示；「已完成」旧记录收尾，不再与新周期记录重复
- **首页层级**：大标题改为「宠物名 + 距下一次到期 N 天」倒计时；无待办时紧急卡降级为浅色提示条；「最近记录」只保留就诊/体重/已完成，不再与「即将到来」重复
- **记录管理**：时间线卡片新增删除入口（hover 显示 ✕，触屏半透明常驻）；体重输入严格校验正数
- **文案一致**：iCloud 同步/家人共享/导出统一标注「规划中」，付费墙不再承诺未上线能力；提前提醒补充「当天」选项
- **细节**：出示模式地点列省略号截断；ESC 可关闭弹层/全屏遮罩；付费墙关闭按钮补 aria-label

## 快速开始

`index.html` 是唯一文件，CSS 与 JS 已全部内联。**双击用浏览器打开即可运行**，无需服务器、无网络依赖。数据保存在浏览器 localStorage（key：`phb_proto_v1`）。

## 技术要点（接手人需知）

- **纯前端**：单文件 HTML + 原生 JS，无框架、无构建。视图函数返回 HTML 字符串，`render()` 统一渲染
- **SVG 图标系统**：脚本头部 `ICON_PATHS`（24 个线性图标），`icon(name, size)` 生成内联 SVG——不用 emoji，保证跨平台渲染
- **设计令牌**：文件顶部 CSS `:root`（暖纸底 `#F6F1EA`、主色柿橙 `#E8764B`）
- **周期表**：联苗/狂犬 12 月、体内驱虫 3 月、体外驱虫 1 月（默认建议值，文案统一标注「遵兽医医嘱」）
- **中文化日期**：`dateField()` 助手 = 中文显示按钮 + 隐藏原生 date input（showPicker）；`addMonths()` 带月末钳制
- **提醒派生**：`withStatus(r)` 为任意记录计算 生效中/临期/逾期 状态，时间线与首页统一走它，避免徽标漏显示
- **照片入库**：`compressImage()` 先压缩到长边 1280px/JPEG 0.7 再存 localStorage；`save()` 有配额保护
- **演示数据**：`loadSample()` 生成示例猫「布丁」；示例疫苗本为内联 SVG data-URI，日期相对演示台「今天」动态生成
